# Alafia Tile & Marble website

A complete static website. No build, installation, API keys or paid services needed.

## Add to GitHub
1. Unzip this package.
2. Upload all contents to your repository root. Keep index.html at the root beside style.css, script.js and the assets folder.
3. For GitHub Pages, choose Settings > Pages > Deploy from a branch > main > / (root).

Open index.html directly for a local preview.

## Edit
- index.html: wording, phone numbers and social links.
- style.css: colors, layout and animations. Brand colors are near the beginning and in the final branding block.
- script.js: the 1.6-second opening and scroll reveals. The cover overlaps the first-page animations to avoid a second wait.
- assets/: official logo and two project photos downloaded from the company's public Facebook pages.

Call/text buttons open the visitor's device apps. Facebook and Instagram links open the company's profiles. No message is sent automatically; no contact form or server is required.

Brand colors are sampled/visually approximated from the logo rather than an official brand guide. Business information was taken from public listings; confirm phone, services and service area with the owner before public launch. No reviews, awards, prices or project guarantees were invented.
